## 요약

- **"실험에서 운영으로" — AI가 트렌드 항목이 아니라 전제조건이 됨.** Capgemini(Top Tech Trends 2026)는 "실험적 AI의 시대가 끝나고 신뢰할 수 있는 데이터·거버넌스·확장 가능한 아키텍처라는 기반을 다시 쌓는 해"로 2026을 규정하고, Autodesk(AI Pulse)도 조사 축을 아예 "experimentation → implementation"으로 잡았습니다. 디자인 조직에게는 "AI를 쓰는가"가 아니라 "AI를 운영 가능한 프로세스로 만들었는가"가 질문입니다.

- **탐색·발견의 진입점이 검색창에서 AI 에이전트로 이동.** Accenture Song(Consumer Pulse 2026)은 AI 에이전트가 브랜드 가치 평가의 새 규칙을 만든다고 보고, 오픈서베이(AI 검색 트렌드 2026)는 국내에서 ChatGPT·Gemini 이용률이 급등하고 전통 포털 입지가 약화되며, 원하는 답이 없을 때 포털로 되돌아가지 않고 **질문을 고쳐 쓰거나 다른 AI 모델로 교차 이동**하는 행동이 굳어졌다고 관측합니다. HTTP Archive 2025 Web Almanac도 이번 판에서 Generative AI 챕터를 신설했습니다.

- **디자이너 직무의 무게중심 이동: UI 산출물 → 판단·신뢰·전략.** Figma(State of the Designer 2026)는 "A field in flux / 크래프트의 재정의 / 창작 자유와 만족도"를 핵심 축으로 잡았고, YOUSPI·World Usability Congress(2026 UX Trends Report)는 한 발 더 나아가 "UX는 더 이상 무시당하지 않는다. 대신 **적극적으로 잘못 관리되고 있다(actively under-managed)**"고 진단하며 리더십·번아웃·윤리적 AI 확장을 주요 의제로 올렸습니다.

- **공정성·투명성이 경험 품질의 새로운 측정 항목.** Capgemini(What matters to today's consumer 2026)는 소비자 가치 인식의 기준이 가격/편의에서 **fairness와 데이터 투명성**으로 이동했고, 기술이 스트레스를 줄여주지만 복잡한 의사결정에서는 사람의 개입이 여전히 필수라고 정리합니다 — 자동화의 기본값과 휴먼 에스컬레이션 설계가 UX 요구사항이 됩니다.

- **기초 웹 품질(성능·접근성)은 여전히 미해결 과제.** 2025 Web Almanac(2026-01 발행, 561p)은 17M+ 사이트 실측 기반으로 Performance·Accessibility·Privacy·CMS·Ecommerce를 다루며, 트렌드 담론과 실제 배포된 웹의 격차를 수치로 보여주는 이 컬렉션의 유일한 **실측 벤치마크**입니다.

- **물성·감각 트렌드도 다시 전면에.** KIDP CMF 트렌드 보고서 2026-2027은 매크로 트렌드를 인테리어·가전·컨슈머 테크·자동차·패션·패키징 6대 산업의 소재/컬러/마감 전략으로 내려 쓰며, 화면 밖 촉각·질감 경험을 제품 디자인 언어로 연결합니다.
